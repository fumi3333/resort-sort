# リゾートソート（Resort Sort）

全国のリゾートバイト求人を横断比較・検索できるアグリゲーションプラットフォームです。

**公開サイトURL**: [https://resort-sort.fumiproject.dev/](https://resort-sort.fumiproject.dev/)

---

## 概要

「リゾートソート」は、大手派遣会社（ダイブ、グッドマンサービス、アルファスタッフ等）の求人情報を自動集約し、以下の条件でリアルタイムに並び替え・絞り込みができるサービスです。

- **時給順ソート**: 全国の最高時給求人を瞬時に比較
- **寮の完全個室判定**: 相部屋リスクのない完全個室のみを抽出
- **食事無料・交通費支給**: 手取り額を最大化するための福利厚生フィルター
- **地域・職種別検索**: 沖縄・北海道・スキー場・温泉地などの人気エリア絞り込み

---

## 特徴・技術仕様

- **高速軽量レンダリング**: 初期HTMLに主要求人を静的埋め込み（Prerender）し、SEO評価と表示速度を最大化
- **構造化データ対応**: schema.org（WebSite / ItemList）によるGoogle検索リッチリザルト対応
- **完全モバイル対応**: スマートフォン・PC双方に最適化されたUI
- **法令遵守（コンプライアンス）**:
  - 厚生労働大臣許可番号の明記
  - 消費者庁ステルスマーケティング規制（PR表記）ガイドライン準拠
